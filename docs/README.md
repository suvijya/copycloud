# CopyCloud Documentation

## Overview

CopyCloud is a cross-device clipboard synchronization application that allows users to sync text and images between desktop, mobile, and web.

## Architecture

- **Server**: Fastify-based REST API with JWT authentication
- **Desktop**: Electron app with system tray integration
- **Mobile**: React Native/Expo for iOS and Android
- **Shared**: Common TypeScript types and utilities
