# Glossary

## Terms

### Clipboard Sync
The process of sharing clipboard content across multiple devices in real-time.

### End-to-End Encryption (E2EE)
A communication system where only communicating users can read messages.

### JWT (JSON Web Token)
A compact, URL-safe means of representing claims to be transferred between two parties.

### WebSocket
A computer communications protocol providing full-duplex communication channels over a single TCP connection.

### System Tray
A graphical user interface element that provides access to system functions and running applications.

### Hot Reload
The ability to see changes reflected in real-time without restarting the application.

### Monorepo
A software development strategy where code for multiple projects is stored in a single repository.

### Fastify
A web framework for Node.js with a focus on performance and low overhead.

### Electron
A framework for building cross-platform desktop applications with web technologies.

### React Native
A framework for building native mobile applications using React.
