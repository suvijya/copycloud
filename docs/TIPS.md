# Tips and Tricks

## Productivity

### Quick Actions
- Double-click tray icon to toggle sync
- Right-click for context menu
- Drag and drop text to sync

### Keyboard Mastery
- `Ctrl+Shift+C/V` - Basic sync
- `Ctrl+Shift+1-9` - Quick paste from history
- `Ctrl+Shift+F` - Search clipboard history

## Power Features

### Batch Sync
- Select multiple items
- Copy all at once
- Paste in order

### Pin Items
- Pin frequently used text
- Access from any device
- Never lose important snippets

### Templates
- Save text templates
- Insert with shortcuts
- Share with team

## Performance

### Optimize
- Reduce history size if slow
- Close unused devices
- Use wired connection when possible

### Troubleshooting
- Restart if sync stops
- Check internet connection
- Update to latest version
