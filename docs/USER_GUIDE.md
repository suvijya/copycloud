# User Guide

## Getting Started

### Installation

1. Download from GitHub Releases
2. Run the installer
3. Launch CopyCloud

### First Setup

1. Create an account or login
2. Install on all your devices
3. Login with same account on each
4. Start copying and pasting!

## Features

### Clipboard Sync
- Copy text on Device A
- Paste on Device B instantly
- History available in system tray

### Keyboard Shortcuts
- `Ctrl+Shift+C` - Copy to cloud
- `Ctrl+Shift+V` - Paste from cloud
- `Ctrl+Shift+H` - Show history

### Settings
- Auto-start on boot
- Clipboard monitoring interval
- History size limit
- Theme selection

## Tips

1. **Keep devices connected** for real-time sync
2. **Use strong password** for security
3. **Check history** for previously copied items
4. **Report bugs** on GitHub

## FAQ

**Q: Does it work offline?**
A: No, internet connection is required.

**Q: Is my data safe?**
A: Yes, we use encryption for all transfers.

**Q: Can I sync files?**
A: File sync is coming in a future update.
