## Unique Selling Points

1. **Self-hosted option** - Full control over data
2. **Open source** - Transparent and customizable
3. **Cross-platform** - Windows, macOS, Linux, iOS, Android
4. **Real-time sync** - Instant clipboard updates
5. **Free tier** - No paywall for basic features
