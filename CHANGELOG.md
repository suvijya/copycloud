# Changelog

All notable changes to CopyCloud will be documented in this file.

## [0.1.0] - 2026-06-12

### Added
- Initial project structure with monorepo setup
- Fastify server with authentication
- Clipboard sync API endpoints
- Device management API
- Electron desktop app scaffold
- React Native mobile app scaffold
- Shared TypeScript types and encryption utilities
- Graphify knowledge graph integration
- Docker configuration
- Design mockup HTML

### Changed
- Port changed from 3000 to 3001 to avoid conflicts
- Switched from @fastify/jwt to jsonwebtoken for auth
